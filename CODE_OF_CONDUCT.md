# Código de conducta · Code of Conduct

Este código se basa en el [Contributor Covenant 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/), publicado con licencia [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), y está adaptado y resumido para este proyecto. Lo que no se resume aquí se rige por el texto original.

## Nuestro compromiso

Queremos que participar en Dormer sea una experiencia libre de acoso para todas las personas, sin importar su edad, cuerpo, discapacidad, etnia, identidad o expresión de género, nivel de experiencia, nacionalidad, apariencia, raza, religión u orientación.

## Qué esperamos

- Trato respetuoso y empático; aceptar críticas con gracia y darlas con cuidado.
- Centrarse en lo que es mejor para la comunidad, no solo para uno mismo.
- Asumir buena fe, sobre todo al ayudar a quien empieza.

## Qué no se tolera

- Lenguaje o imágenes sexualizados, y atención sexual no deseada.
- Insultos, ataques personales, trolleo o comentarios despectivos.
- Acoso público o privado.
- Publicar información privada de otras personas sin permiso.
- Cualquier conducta que razonablemente se considere inapropiada en un entorno profesional.

## Responsabilidades y alcance

Los mantenedores aclaran estas normas y pueden editar, eliminar o rechazar comentarios, *commits*, código, *issues* y otras contribuciones que no las respeten, explicando el motivo cuando sea apropiado. El código se aplica en todos los espacios del proyecto (repositorio, discusiones, canales) y cuando alguien representa al proyecto en público.

## Cómo reportar

Escribe a los mantenedores en privado usando el contacto indicado en el perfil del repositorio (o un aviso privado de GitHub). Todos los reportes se revisan con prontitud y de forma confidencial, respetando la privacidad de quien reporta.

## Consecuencias

Los mantenedores siguen las [guías de aplicación del Contributor Covenant](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/#enforcement-guidelines): corrección, advertencia, suspensión temporal o expulsión permanente, según la gravedad.

---

*English:* We follow the Contributor Covenant 2.1 (CC BY 4.0), adapted. Be respectful, assume good faith, and don't harass anyone. Report concerns privately to the maintainers via the contact listed on the repository profile (or a private GitHub advisory). Maintainers may remove contributions that violate this code and apply the Covenant's enforcement ladder.
